# B581 ETL Project: OpenEMR → Primary Care → HL7 ADT

Welcome to our Final Project website for the B581 course.  
This project demonstrates a complete ETL (Extract, Transform, Load) pipeline built using:

- Python  
- FHIR REST APIs (OpenEMR & Primary Care EHR)  
- SNOMED CT Terminology Services  
- ICD-10 Mapping  
- HL7 v2 ADT Message Generation  

## Project Deliverables
- End-to-end ETL pipeline (Tasks 1–5)
- FHIR authentication, extraction, and transformation
- SNOMED parent/child concept derivation
- ICD-10 mapping for diagnoses
- HL7 v2 ADT message generation using Python (hl7apy)
- This GitHub Pages website documenting the project

Navigate the website to explore the entire pipeline, insights, and team contributions.
